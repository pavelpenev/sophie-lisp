# Sophie Lisp

Sophie Lisp is a conservative, spec-first, purely additive Common Lisp
language extension. Everything Sophie adds is a supplement — no ANSI
behaviour is changed, redefined, or removed. This repo contains the
specification, reference implementation, test suite, and documentation.

## Git

`main` is the main branch. Do not commit directly to `main`. Implementation
work may be committed on a dedicated branch; keep regular Git checkpoints.
Do not push without explicit approval.
